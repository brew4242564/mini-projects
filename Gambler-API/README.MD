# GamblerAPI

GamblerAPI simulates 100 bets in a simplified way, taking into account a small commission and two default probabilities (45/55 and 50/50).
In addition, it also offers the option to modify the commission frequency and the probabilities of winning.

## Customizable Parameters
To modify the commission rate or the win probabilities, add “freq” or “chances.”

### Example
```
https://gamblingapi-v8z9.onrender.com/gambling?freq=5&chances=90
```
